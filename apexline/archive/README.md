# Archived data from earlier physics versions

`physics-2/` holds the 275-track campaign data, benchmark/medal-ghost replays and optimiser genes produced with the *bicycle-model* physics (`apexline-sim-2`).
They are **incompatible** with the current arcade physics (`apexline-sim-3`): replaying their inputs gives different results, so they are kept only for reference and are not shipped or loaded.
Player records made under older physics are archived inside each save (`profile.archive`) the first time the new version loads.
