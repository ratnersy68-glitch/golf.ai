# Glossary

> **📌 Note:** This glossary is deliberately long — every term used anywhere in this book
> should be findable here, in plain English, even if you remember only roughly what it
> sounded like. Terms are alphabetical; cross-references point back to the chapter where the
> term matters most.

| Term | Definition |
|---|---|
| A/R ratio | A measurement of a turbo's turbine/compressor housing shape that affects spool speed vs. high-RPM flow — see [Turbo Planning Guide](#turbo-planning-guide) |
| Aftermarket | Any part made by a company other than the original car manufacturer |
| AFR | Air/Fuel Ratio — the ratio of air to fuel in the combustion mixture; stoichiometric for gasoline is ~14.7:1 |
| Aspect ratio (tire) | Sidewall height as a percentage of tire section width — see [Wheel & Tire Guide](#wheel--tire-guide) |
| ATF | Automatic Transmission Fluid |
| Backspacing | The distance from a wheel's mounting face to its inner edge — related to, but distinct from, offset |
| Bedding in (brakes) | The break-in procedure for new pads/rotors that transfers an even layer of pad material onto the rotor — see [Brake Guide](#brake-guide) |
| Big brake kit (BBK) | An aftermarket brake upgrade including larger rotors and often multi-piston calipers |
| Blow-off valve / diverter valve (BOV) | A valve that releases pressurized intake air when the throttle closes suddenly, preventing compressor surge |
| Boost | Positive intake pressure above atmospheric, created by a turbo or supercharger, usually measured in psi |
| Bolt pattern | The number and diameter of a wheel's lug holes — must match the car's hub exactly |
| Bushing | A rubber or polyurethane joint that lets suspension arms pivot while damping vibration and controlling movement |
| Camber | The inward/outward tilt of the wheel/tire when viewed from the front of the car |
| Caster | The forward/backward tilt of the steering axis, affecting straight-line stability and steering feel |
| Ceramic coating | A liquid polymer applied to paint/wrap for added protection and shine, distinct from wax |
| Compressor (turbo) | The wheel that pressurizes incoming intake air, driven by the turbine on the same shaft |
| Contact patch | The actual area of a tire touching the road at any moment |
| Control arm | A suspension arm that locates the wheel and controls its geometry through suspension travel |
| Corner balance | Adjusting suspension so each of the four corners carries its intended share of the car's total weight |
| Coilover | A suspension unit combining a coil spring and a damper (shock), typically height- and often damping-adjustable |
| Cupping (tire wear) | A scalloped tire wear pattern usually caused by worn-out shocks/dampers failing to control tire motion |
| Damper / shock | The component that controls how fast a spring moves, preventing endless bouncing |
| Detonation / Knock | Uncontrolled, secondary ignition of the air/fuel mixture inside the cylinder, distinct from and dangerous compared to normal combustion |
| DOT rating (brake fluid) | A classification (DOT 3/4/5/5.1) indicating brake fluid's boiling point and chemistry — see [Brake Guide](#brake-guide) |
| Downpipe | The section of exhaust piping immediately after the turbo's turbine housing |
| Duty cycle (injector) | The percentage of time a fuel injector is open versus closed at a given RPM/load — running near 100% leaves no headroom |
| Dyno / Dynamometer | A machine that measures an engine or vehicle's power output, typically at the wheels (chassis dyno) |
| ECU | Engine Control Unit — the computer controlling fuel, ignition timing, and other engine parameters |
| Fade (brake fade) | Reduced braking performance from excessive heat buildup in the pads/rotors |
| Feathering (tire wear) | A tire wear pattern where tread blocks wear unevenly edge-to-edge, usually from toe misalignment |
| Fitment | How well a wheel/tire or body part physically fits the car without interference |
| Flare (transmission) | A symptom where engine RPM rises before the next gear engages, indicating clutch/band slip |
| Freeze-frame data | A snapshot of sensor readings captured by the ECU at the moment a diagnostic code was set |
| FSM | Factory Service Manual — the manufacturer's own official repair documentation, including torque specs and procedures |
| Fuel pressure regulator | A component that maintains correct fuel pressure at the injectors under varying conditions |
| Intercooler | A heat exchanger that cools compressed (boosted) intake air before it enters the engine |
| JATCO | The transmission manufacturer that produces the 350Z's RE5R05A 5-speed automatic transmission |
| Knock sensor | A sensor that detects detonation/knock, allowing the ECU (or tuner) to respond by pulling timing |
| Load index (tire) | A code number on a tire's sidewall indicating its maximum rated load |
| LSD | Limited Slip Differential — a differential design that limits speed difference between the two driven wheels for better traction |
| N/A | Naturally Aspirated — an engine with no forced induction (turbo/supercharger) |
| OBD-II | The standardized onboard diagnostics port/protocol used by cars since the mid-1990s |
| Offset (wheel) | The distance from a wheel's centerline to its mounting face — determines how far in/out the wheel sits |
| OE / OEM | Original Equipment (Manufacturer) — factory-spec parts |
| Oversteer | A handling condition where the rear of the car rotates more than expected relative to the front — see [Suspension Guide](#suspension-guide) |
| PPI | Pre-Purchase Inspection |
| Readiness monitor | An internal emissions self-test that resets after a battery disconnect or code clear, and takes time/specific conditions to complete again |
| RE5R05A | The specific JATCO 5-speed automatic transmission used in the automatic 350Z |
| Rev-Up | Nissan's name for the revised VQ35DE cylinder heads/intake introduced partway through the 350Z's production, used in the 2005–2006 model years this book targets |
| Section width (tire) | The tire's width in millimeters, sidewall to sidewall |
| Shift kit | A modification that firms up and speeds up automatic transmission shifts, typically via modified valve body hydraulics |
| Spool (turbo) | The turbo building rotational speed and boost after a throttle input |
| Sprung / unsprung weight | Sprung weight is supported by the springs (body, chassis); unsprung weight is not (wheels, tires, brakes, suspension arms) — lower unsprung weight generally improves handling |
| Stall speed | The RPM at which a torque converter allows the engine to spin relative to the transmission input shaft before fully coupling |
| Standalone ECU | An aftermarket engine computer that fully replaces the factory ECU, offering complete tuning control |
| Stoichiometric | The chemically ideal air/fuel ratio for complete combustion — approximately 14.7:1 for gasoline |
| Strut tower brace | A bar connecting the two strut towers to reduce chassis flex |
| Surge (turbo) | A compressor instability caused by a suddenly closing throttle against built-up pressure, prevented by a blow-off/diverter valve |
| Sway bar | A bar linking left and right suspension to resist body roll in corners |
| Timing chain | The chain connecting the crankshaft and camshafts, keeping valve timing synchronized with piston position |
| Toe | The inward/outward angle of the front (or rear) of the tires relative to the car's centerline, viewed from above |
| Torque (engine) | A twisting force the engine produces — the quantity most directly stressing a transmission's clutches/bands |
| Torque (fastener) | How tight a bolt/nut is, measured in a unit like ft-lb, per a specified value — not "as tight as possible" |
| Torque converter | The fluid coupling that connects an automatic transmission to the engine, replacing a manual clutch |
| TPMS | Tire Pressure Monitoring System — sensors that report tire pressure to the dashboard |
| Trans temp | Transmission fluid temperature — a critical gauge once the car is boosted, see [Maintenance Guide](#maintenance-guide) |
| Tune / Map | The specific set of fuel, ignition, and boost parameters programmed into the ECU |
| Turbine (turbo) | The wheel spun directly by exhaust gas flow, connected by a shaft to the compressor |
| Turbo lag | The delay between throttle input and the turbo reaching effective boost pressure |
| Understeer | A handling condition where the front of the car resists turning as much as steering input requests — see [Suspension Guide](#suspension-guide) |
| Valve body | The hydraulic control component inside an automatic transmission that directs fluid to control shifts |
| VDC | Vehicle Dynamics Control — Nissan's stability control system |
| VIN | Vehicle Identification Number — a car's unique 17-character identifier, used to verify title/history/parts fitment |
| VQ35DE | The 3.5L V6 engine used in the 2005–2006 350Z, in "Rev-Up" form for these model years |
| Wastegate | A valve that controls exhaust flow to the turbo's turbine, regulating boost pressure |
| Weight transfer | The shift of a car's effective weight between front/rear or side/side under acceleration, braking, or cornering |
| Wideband (O2 sensor / gauge) | An oxygen sensor and gauge capable of accurately reading a wide range of air/fuel ratios, used for tuning |
| WHP / whp | Wheel Horsepower — power measured at the wheels on a dyno, after drivetrain losses from the crank figure |
