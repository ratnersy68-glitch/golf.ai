# Maintenance Log

> **📌 Note:** This log tracks routine maintenance — fluids, wear items, inspections. Track
> performance modifications separately in the [Modification Log](#modification-log). A
> reusable blank entry template is available at
> `templates/maintenance-log-entry-template.md`.

## How to use this log

Add one row per service event, oldest first. Include odometer reading so intervals in the
[Maintenance Guide](#maintenance-guide) can be tracked accurately. The rows below are
**sample data** — delete them and start your own log once your build begins.
